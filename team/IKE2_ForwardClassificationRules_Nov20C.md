IKE2 FORWARD CLASSIFICATION — OPERATING RULES + CHART
League 1 (DCHL) — November 20, 2026
RULE 1 — FOLLOW THE STEPS IN ORDER
Step 1 sets the level. Step 2 sets the type. Step 3 joins them into the final identity.
Do not skip a step. Do not classify by reputation, intuition, or a single standout attribute. Use only the chart and the roster ratings.
STEP 1 — LEVEL
Count the Lucky Seven (CK, SK, DF, EN, PA, SC, PH) rated 90 or higher.
* 5 or more = Franchise (if EN is under 85, the player still receives his type but carries the Cornerstone tag)
* 4 = Cornerstone
* 3 = Elite
* 2 = Core
Level is only a tag. It never decides a type and never blocks a type.
STEP 2 — TYPE
Check the player against every line on the chart. A player qualifies for a type only if he meets every requirement on that line. Partial credit does not count.
He receives exactly one type. If he qualifies for more than one, resolve it in this order:
A. Moose always wins.
B. Centre wins. A player listed at C who qualifies for a centre type (200-Foot Centre, Shutdown Centre, Defensive Centre, Second-Line Centre, Third-Line Centre) gets the centre type over any non-centre type.
C. Upper types beat lower types. Among upper types, go from the top: the higher line wins.
    90 line: Moose, Hammer, Scorpion, Magician, 200-Foot Centre, Shutdown Centre, Shutdown Forward
    87 line: Dangler
    85 line: PowerMaker, Playmaker, Defensive Centre, Defensive Forward, Second-Line Centre
    83 line: Sniper
D. Lower types: Offensive Catalyst, Two-Way Forward, Power Forward, Third-Line Centre, Checker, Grinder, Energy Forward, Pit Bull, PK Specialist.
    The line does not decide between lower types. Total the required attributes of each lower type he qualifies for. Eliminate the lowest total, and keep eliminating until one type remains.
E. Ties.
    Two upper types on the same line: the type that requires CK wins. If neither or both require CK, the higher total of required attributes wins.
    Two lower types with the same total: the type that requires CK wins.
STEP 3 — IDENTITY
Final identity = Level + Type. Examples: Elite Dangler, Cornerstone Hammer, Franchise Magician, Core Grinder.
Never change the type because of the level. Never change the level because of the type.
RULE 2 — NUMBERS ARE LITERAL
* "87 or higher" includes 87
* "Below 80" does not include 80
* "Above 80" does not include 80
* "83 to 86" includes both 83 and 86
* "At least 7 higher" means a difference of 7 or more
RULE 3 — POSITION AND FACE-OFFS
* "Listed at C" means the roster shows Centre
* "Wing" means the roster shows L or R
* A player listed at both C and wing is checked for both; Rule B then applies
* FO is mandatory wherever the chart lists it
RULE 4 — RATINGS ONLY
Types are determined solely from ratings. Season statistics are used only later to verify whether the player is performing to type. They never change the classification.
RULE 5 — DATA SOURCE
Use only current pro-roster forwards from the official roster file. State the roster file used. Free agents and farm players are not classified.
RULE 6 — NO SILENT CHANGES
Chart numbers and rules remain exactly as written until Dave changes them. Any proposed change must be clearly labelled as a proposal.
RULE 7 — VERIFY BEFORE REPORTING
Confirm: correct roster file, Lucky Seven count, level, position, FO, every number on the type's line, conflicts resolved by A–E, and final identity = Level + Type. If a result is wrong, fix the result. Do not change the rule to fit the result.

Result: Grinder.
